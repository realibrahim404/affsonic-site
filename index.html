AffSonic

Affiliate content, from product to published post.

AffSonic is a self-hosted tool that finds affiliate products, drafts the copy and creatives for them, and publishes the result to the channels you have connected.

What it does

  • Imports products from affiliate programmes such as Amazon Associates and AliExpress.
  • Drafts titles, descriptions and creatives for each product.
  • Publishes and schedules posts to Pinterest, Medium and WordPress.
  • Adds an affiliate disclosure to every post it creates.
  • Tracks what was published and how each post performed.

How it runs

AffSonic runs on the operator's own machine. There is no shared service and no public sign-up: each installation connects only the accounts its own operator has authorised.

Pinterest integration. AffSonic connects to Pinterest through the official Pinterest API using OAuth. It reads the connected account's profile and boards and creates Pins on that account. It never accesses another Pinner's private data, and access can be revoked at any time from Pinterest's own security settings.
